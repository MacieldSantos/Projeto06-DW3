# Projeto 06 - Agenda de Contatos

Aplicação de agenda de contatos desenvolvida para a disciplina de Desenvolvimento Web III.

## 🚀 Funcionalidades
- CRUD Completo de Contatos (Nome, E-mail, Telefone, Data de Nascimento e Endereço).
- Preenchimento automático do endereço via consumo da API ViaCEP.
- Persistência em Banco de Dados SQLite.
